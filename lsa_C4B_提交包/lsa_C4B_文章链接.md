## 四、传播设计（distribution 维度）

### 1. 渠道矩阵

| 渠道 | 动作 | 目标 |
|------|------|------|
| 微信公众号 | 主发布 | 沉淀 + 长期可检索 |
| Elite20 学习群 | 同步分享链接 | 触达同侪，触发讨论与互助 |
| 朋友圈 / 个人主页 | 转发 + 一句话点评 | 扩大非技术圈层触达 |
| 知乎 / 即刻 | 同内容转 Markdown 版再发 | 多平台分发（技能已预留多格式输出方向） |

### 2. 数据追踪

| 指标 | 观察点 | 用于 |
|------|--------|------|
| 阅读量 | 发布后 24h / 72h / 7d | 判断标题与选题吸引力 |
| 打开率（阅读/送达） | 后台「数据」页 | 判断标题质量 |
| 完读率 | 后台「图文分析」 | 判断正文结构是否拖沓 |
| 分享/在看 | 后台互动数据 | 判断观点是否值得传播 |
| 涨粉数 | 后台粉丝数据 | 判断选题是否命中目标人群 |

**追踪工具**：公众号后台「内容分析 + 用户分析」；7 天后汇总成一张复盘表（见 AAR）。

### 3. 互动设计

- **文末行动号召**：结尾抛出「把你的想法变成一篇发出去的文章」，引导读者留言自己的选题。
- **评论区引导**：发布后置顶一条评论，抛出问题「你最近一次被排版坑过是什么场景？」，收集真实痛点反哺技能迭代。
- **反馈闭环**：把读者反馈的排版问题记入 `lsa_C4B_wechat-publisher` 的迭代清单（见 AAR「下一步」）。
